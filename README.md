# RealWave

風、光、波のあいだへ。WebGL2 と Web Audio で生成する、リアルタイムの海と波音のデモです。Windows 版 Chrome と GeForce RTX 2060 を想定し、外部ライブラリ・動画・音源・CDN に依存せず動作します。

## 体験する

GitHub Pages: https://githubseaotter.github.io/RealWave/

「音とともに、海へ」をクリックすると、映像に集中するモードとステレオ音声が始まります。音声は Chrome の自動再生制限に合わせ、ユーザー操作後に開始します。ヘッドホン推奨です。

- 夕凪・青い海・荒天の3シーン。空と光が滑らかに切り替わります。
- ドラッグで見渡し、マウスホイールで視点の高さを変更。
- 「海を調整」で波・風・音量・描画品質・カメラのゆらぎを変更。
- **F**: 全画面、**H**: 操作画面表示、**M**: 音声、**Space**: 波と音を一時停止、**Esc**: 設定を閉じる。
- タブが非表示になると描画と音声を休止します。

## RTX 2060 / Windows / Chrome

1. Chrome と NVIDIA ドライバーを更新します。
2. Chrome の「設定 → システム → グラフィック アクセラレーションが使用可能な場合は使用する」を有効にします。
3. 最初は「自動」で試してください。GPU の計測時間に応じて内部解像度を調整します。設定パネルで FPS と描画解像度を確認できます。
4. 品質「高」は最大 1920×1080 ピクセル相当、「最高」は最大 2560×1440 ピクセル相当、「軽量」は最大 1280×720 ピクセル相当です。縦横比を維持し、幅と総ピクセル数の両方を制限します。

RTX 2060 実機の性能測定は未実施です。60 FPS は自動画質の目標であり、保証値ではありません。Linux Chromium のソフトウェア WebGL2 環境で、シェーダーのコンパイル、描画、シーン切替、音声出力、操作、レスポンシブ表示を検証しています。

## 描画と音響

- 分散関係 `ω = √(gk)` に基づく複数方向の波を、GPU で半精度の高さ・勾配テクスチャに毎フレーム計算します。
- 高さ場をレイトレースし、フレネル反射、太陽のスペキュラー、透過光の近似、風の細波、移流する白波、雲、距離による霞を合成します。
- 遠景の法線にはミップマップを使い、細かな波のちらつきを抑えます。浮動小数点レンダーターゲットが使えない場合は解析的な波の描画に切り替えます。
- 独立した5層のノイズ、低域・高域フィルター、ステレオパン、コンプレッサーで、寄せ引きと風音を生成します。主波の位相を音量と帯域の変化にも使います。
- 波形・音声・カメラは共通の時間を使い、一時停止と再開に対応します。WebGL コンテキスト喪失からの復帰にも対応します。

自然な見た目を優先した近似モデルです。流体力学の厳密な計算、海岸への砕波、実測の海況再現ではありません。波と風の設定は演出用の目安です。表示座標も架空の海景の設定です。

## ローカルで実行

ビルドやパッケージのインストールは不要です。

```sh
python3 -m http.server 4173
```

http://localhost:4173/ を開きます。ES Modules を使用するため、HTML を `file://` で直接開く方法には対応していません。

```sh
npm run check
```

JavaScript の構文を検査します。アプリ本体に npm 依存パッケージはありません。

## GitHub Pages

`.github/workflows/pages.yml` が `main` への push 時に、構文検査と静的ファイルの公開を行います。初回にリポジトリの **Settings → Pages → Source → GitHub Actions** を有効にする必要がある場合があります。公開されるのは HTML / CSS / JavaScript / favicon のみです。
